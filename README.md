# 🛡️ Safeonix

Safeonix is an AI-powered Fraud Detection System built with **Python**, **Streamlit**, and **Machine Learning**. It helps detect suspicious financial transactions in real time using a trained XGBoost model.

---

## 🚀 Features

- 🔍 Real-time Fraud Prediction  
- 📊 Interactive Dashboard  
- 📁 CSV Bulk Transaction Upload  
- 📧 Email Alerts for High-Risk Transactions  
- 📜 Prediction Logs & History  
- ⚡ Fast and Accurate ML Model  

---

## 🧠 Tech Stack

- Python  
- Streamlit  
- Scikit-learn  
- XGBoost  
- Pandas  
- NumPy
